# Active Architecture Decision Records

> **Tier**: Current Milestone
> **Rolled at**: Milestone boundary — moved to memory/archive/milestone-N/
> **Updated by**: technical-director, lead-programmer

---

## Purpose

ADRs that are open, under active consideration, or recently decided within this
milestone. Agents working on any task that touches a listed system must read the
relevant ADR before proceeding.

---

## ADR Format

```
### ADR-NNNN: [Title]
Status: Proposed | Accepted | Superseded | Deprecated
Date: YYYY-MM-DD
Decision-log ref: DEC-NNNN

Context: [1-2 sentences on why this decision is needed]
Decision: [What was decided — or what options are still open]
Consequences: [What changes as a result]
Open questions: [Unresolved items blocking finalization]
```
