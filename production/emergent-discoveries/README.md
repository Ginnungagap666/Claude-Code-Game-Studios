# Emergent Discovery Register

All emergent discoveries — unscripted cross-system interactions that may be
features or bugs — are tracked here. See `.claude/docs/emergent-design-protocol.md`
for filing and review procedures.

## Directory Structure

```
emergent-discoveries/
  pending/     ← Agent files ED-NNN here; awaiting human review
  feature/     ← Human confirmed: this is a feature
  bug/         ← Human confirmed: this is a bug; fix normally
```
